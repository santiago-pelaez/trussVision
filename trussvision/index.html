ADVANCED // METHOD & EXPORT

2D trusses use a linear elastic pin-jointed stiffness method. Beams use statically determinate vertical point and distributed loads. Additional verified equations support reviewed springs, ideal pulley systems, friction thresholds, composite polygons, and explicitly defined 2D/3D rigid-body reactions. Unrecognized or underdetermined problems are never assigned invented answers.
